## 2. 프로젝트 개요 🛠️

### **프로젝트명**: 외산차 등록 현황 및 점유율 분석 대시보드

- **목적**:
  - 🚙 외산차 및 국산차의 등록 현황을 사용자에게 제공.
  - 📊 시장 점유율 분석 및 트렌드 파악.
  - 📝 FAQ 검색 및 기업별 데이터 제공.
- **주요 기능**:
  1. 🌍 전국 외산차 등록 현황 조회.
  2. 🔍 브랜드별 외산차 등록 현황 분석.
  3. 📋 2025년 TOP 5 외산차 기업 FAQ 조회.
  4. 📈 과거 10년간 데이터 분석 및 시각화.
  5. 🔮 2025년 판매량 예측.
